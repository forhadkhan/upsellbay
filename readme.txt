WooCommerce-native order bumps and AOV offers for product, cart, checkout, and thank-you journeys.

== Description ==

UpsellBay is a premium WooCommerce-native AOV offer engine. It helps WooCommerce merchants increase average order value by rendering native, measurable offers at key moments:

* **Product page:** Product add-ons or frequently-bought-together offers.
* **Cart:** Cross-sells and threshold/helper offers.
* **Checkout:** Order bumps on classic checkout and Block Checkout.
* **Thank-you page:** Safe follow-on checkout offers after the primary order is complete.

UpsellBay preserves your existing WooCommerce checkout and natively supports modern WooCommerce architecture like High-Performance Order Storage (HPOS) and Block Checkout. It provides offer-level analytics including views, accepts, dismissals, attributed revenue, and AOV impact estimates.

== Installation ==

1. Upload the `upsellbay` directory to your `/wp-content/plugins/` directory.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Navigate to **WooCommerce > UpsellBay** to enter your license key and start creating offers.
